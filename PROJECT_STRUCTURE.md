# Project Structure

This is a standalone, portable tool for decrypting Antigravity IDE conversation files.

## Files

- **`antigravity_decrypt.py`** - Main decryptor script (standalone, all functionality included)
- **`requirements.txt`** - Python dependencies (cryptography, protobuf)
- **`README.md`** - Complete documentation and usage guide
- **`LICENSE`** - MIT License
- **`CHANGELOG.md`** - Version history
- **`.gitignore`** - Git ignore rules (excludes decrypted files, keys, etc.)

## Dependencies

- Python 3.6+
- `cryptography` - For AES decryption
- `protobuf` - For parsing protobuf wire format

## Usage

See `README.md` for complete usage instructions.

## Standalone

This directory contains everything needed to decrypt Antigravity conversation files. No other files or directories from the original project are required.
